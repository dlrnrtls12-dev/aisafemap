# AI 산악사고 통합 대응 플랫폼

## 제품 목적

소방안전 빅데이터와 기상·지도·지형 등 외부 데이터를 활용하여 산악사고 발생 시 신고자, 소방대, 지휘관 및 유관기관이 실시간으로 상황을 공유하고 구조 의사결정을 지원받는 애플리케이션을 개발한다.

AI는 산악사고 통계, 출동 통계, 기상, 지형, 신고자 상태를 분석하여 위험도, 구조 경로, 필요 장비 및 대응 방법을 제안한다. AI의 결과는 현장 판단을 보조하는 정보이며 최종 결정은 구조대와 지휘관이 수행한다.

## 주요 사용자

- 신고자
- 소방대원
- 현장 지휘관
- 경찰·군·지자체 등 유관기관
- 시스템 관리자

## 핵심 기능

### 1. 사고별 보안 접속

- 사고마다 고유한 사고 ID를 생성한다.
- 신고자용 링크와 소방대용 링크를 별도로 발급한다.
- 유관기관은 기관과 역할을 확인한 후 접속한다.
- 사고 종료 후 링크는 만료한다.
- 사고 기록은 서버에 계속 보존한다.

### 2. 신고자 정보 수집

신고자는 다음 정보를 입력하거나 공유할 수 있다.

- 이름과 연락처
- 나이, 성별, 키, 몸무게
- 부상 부위와 부상 정도
- 의식, 호흡, 출혈 및 보행 가능 여부
- 기저질환, 복용약 및 알레르기
- GPS 위치와 위치 정확도
- 휴대전화 배터리 상태
- 사진, 음성 및 추가 설명

위급한 상태가 입력되면 구조대 화면에 즉시 경고한다.

### 3. AI 산악안전지도

지도에 다음 정보를 표시한다.

- 신고자 위치와 GPS 오차 범위
- 소방대와 유관기관 참여자의 실시간 위치
- 산 명칭, 고도 및 등산로
- 사고·출동 다발 구역
- 등고선, 경사도 및 위험 구간
- 수색 진행·완료·미수색 구역
- 국가지점번호
- 산악위치표지판
- 간이구조구급함
- 기관별·팀별 수색 인원

경찰, 군, 지자체, 소방 등은 서로 다른 아이콘과 색상으로 표시한다.

### 4. AI 위험도 분석

다음 정보를 종합하여 사고 위험도를 분석한다.

- 과거 산악사고 발생 통계
- 과거 소방 출동 통계
- 현재 위치의 고도와 경사도
- 등산로 이탈 여부
- 현재 및 예보 기상
- 기상특보
- 일출·일몰과 남은 주간 시간
- 신고자의 부상 및 건강 상태
- 구조대 접근 예상 시간

위험도는 `낮음`, `주의`, `높음`, `매우 높음`, `긴급`으로 표시한다.

분석 결과에는 위험도 점수, 주요 위험 요인, 데이터 기준 시각, 신뢰도와 권고 행동을 함께 표시한다.

### 5. 구조 경로 추천

실제 등산로와 지형 데이터를 기반으로 다음 경로를 제안한다.

- 최단 경로
- 최저 위험 경로
- 환자 운반 우선 경로
- 대체 경로

경로 계산에는 거리, 경사도, 고도 변화, 기상, 야간 여부, 위험 구간, 차량 접근 가능성과 신고자 상태를 반영한다.

AI가 실제 데이터에 존재하지 않는 경로를 생성해서는 안 된다.

### 6. 실시간 기상정보

- 현재 날씨
- 기온과 체감온도
- 강수 및 적설
- 풍향과 풍속
- 단기예보
- 기상특보
- 일출 및 일몰 시각
- 일몰까지 남은 시간

각 정보에는 출처와 기준 시각을 표시한다.

### 7. 구조 장비 추천

기상, 지형, 사고 유형, 신고자 상태와 몸무게를 분석하여 필요한 장비를 추천한다.

예시:

- 산악용 들것
- 로프와 확보 장비
- 조명과 예비 배터리
- 방한·보온 장비
- 산소와 자동심장충격기
- 출혈 통제 및 골절 고정 장비
- 통신 중계 장비
- 드론과 열화상 장비

추천 장비별로 우선순위와 추천 이유를 표시한다.

### 8. 응급처치 챗봇

신고자가 응급처치 방법을 질문할 수 있는 챗봇을 제공한다.

챗봇은 검증된 응급처치 자료만 근거로 사용하며, 출혈·골절·저체온증·열사병·낙상 등에 대한 행동 요령을 안내한다.

생명이 위급할 가능성이 있으면 챗봇 대화보다 119와 구조대의 지시를 우선하도록 안내한다.

### 9. 지휘관용 SOP 챗봇

산악사고 대응 SOP와 기관 협업 지침을 검색하여 다음 내용을 지원한다.

- 초기 대응 방법
- 수색 구역 설정
- 기관별 임무 분담
- 추가 인력과 장비 요청
- 현장 안전관리
- 기상 악화와 야간 수색 대응
- 헬기 지원 검토
- 사고 종료 및 보고 절차

답변에는 근거 문서와 관련 조항을 표시한다. 근거를 찾지 못하면 답변을 임의로 생성하지 않는다.

### 10. 실시간 소통

사고 참여자 간에 다음 기능을 제공한다.

- 문자 채팅
- 음성인식 입력
- 메시지 음성 읽기
- 사진 및 음성 전송
- 영상통화
- 중요 메시지와 긴급 알림
- 기관 및 역할 표시

통신이 불안정한 환경에서는 메시지를 임시 저장하고 연결 복구 후 재전송한다.

### 11. 사고 기록 보존

사고 종료 후에도 다음 정보를 서버에 보존한다.

- 사고 기본정보
- 신고자 상태
- 위치 이동 이력
- 채팅과 첨부파일
- 기상정보
- AI 위험도 및 추천 결과
- 구조 경로
- 참여기관과 인력
- 지휘관 지시 및 의사결정
- 사고 타임라인
- 최종 구조 결과

권한이 있는 사용자는 종료된 사고를 조회하고 사후 보고서를 생성할 수 있다.

## MVP 범위

경진대회 시연 버전에서는 다음 기능을 우선 구현한다.

1. 사고 생성
2. 신고자용·소방대용 링크 분리
3. 신고자 GPS 및 상태 입력
4. 산악안전 통합 지도
5. 산·등산로·기상·사고 통계 표시
6. AI 위험도 분석
7. 구조 경로 및 장비 추천
8. 국가지점번호와 산악시설 표시
9. 실시간 문자 채팅
10. 신고자용 응급처치 챗봇
11. 지휘관용 SOP 챗봇
12. 기관별 참여자 위치 표시
13. 사고 기록 저장 및 종료 처리

STT, TTS, 영상통화, 고급 수색구역 분석은 MVP 이후 단계적으로 추가한다.

## 데이터 및 API 연동 원칙

- 승인받은 소방안전 빅데이터 플랫폼 API를 사용한다.
- 기상, 지도, 지형, 등산로 및 일출·일몰 외부 API를 연동한다.
- 실제 API 명세가 확인되지 않은 항목은 임의로 만들지 않는다.
- API별 연동 모듈을 분리한다.
- 화면에 데이터 출처와 기준 시각을 표시한다.
- API 장애에 대비해 캐시 또는 시연용 데이터를 제공한다.
- 시연용 데이터는 실제 데이터와 명확하게 구분한다.

## 보안 원칙

- API 키를 소스코드나 프론트엔드에 작성하지 않는다.
- 실제 API 키는 서버 환경변수로 관리한다.
- `.env` 파일을 GitHub에 커밋하지 않는다.
- 개인정보와 건강정보는 암호화하여 저장한다.
- 역할 기반 접근제어를 적용한다.
- 민감정보 열람 기록을 감사 로그에 남긴다.
- 간이구조구급함 비밀번호는 권한 있는 사용자만 확인할 수 있다.
- 사고 종료 시 실시간 위치 수집을 중단한다.

## 완료 기준

- 신고자와 소방대가 서로 다른 권한으로 접속할 수 있다.
- 신고자의 위치와 상태가 관제 화면에 표시된다.
- 참여기관의 위치와 역할을 지도에서 구분할 수 있다.
- 위험도 결과에 점수와 근거가 표시된다.
- 실제 등산로 데이터를 기반으로 구조 경로를 추천한다.
- 기상과 신고자 상태에 따른 장비를 추천한다.
- 사고 종료 후에도 기록이 서버에 저장된다.
- 모바일 환경에서 핵심 기능을 사용할 수 있다.
- API 키와 개인정보가 GitHub 및 브라우저에 노출되지 않는다.
